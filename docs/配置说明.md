# 配置说明（分层与变量清单）

> 适用版本：2026-10-24 起
> 目标：`.env` 只保留运维必须关心的变量；内部调参用安全默认值或 `MCP_TOOLS_PROFILE` 档位；
> 资源级配置放数据库/控制台，不和环境变量混在一起。

---

## 1. 三层配置

| 层 | 位置 | 谁维护 | 内容 |
|---|---|---|---|
| **运维层** | `mcp-gateway/.env`（本地）/ 部署环境注入的环境变量（生产） | 运维 | 数据库、密钥、对外地址、Redis、身份下传开关、工具档位 |
| **高级层** | Spring 属性（YAML 默认值 + `--mcp.tools.*` / `MCP_TOOLS_*`） | 开发/排障 | 分页、检索策略、分片、探活间隔、熔断、embedding 模型等 |
| **资源层** | MySQL：`mcp_server` / `mcp_endpoint` / `mcp_namespace` / `mcp_tool` | 运营 | 身份模式、audience、公钥、暴露模式、热工具、阈值、状态 |

优先级（高 → 低）：

```text
命令行参数 / 显式单项环境变量
  > MCP_TOOLS_PROFILE 预设
  > YAML / Java 默认值
```

资源层的 Server 配置覆盖全局身份模式（`INHERIT` 时沿用全局），但不影响进程级参数。

## 2. 运维层：`.env` 清单（约 20 个）

### 2.1 必填（生产）

| 变量 | 说明 |
|---|---|
| `MYSQL_ROOT_PASSWORD` | 仅首次初始化 MySQL 时使用（手工建库/导入脚本）；jar 不读取 |
| `MYSQL_DATABASE` | 固定 `mcp_gateway` |
| `MYSQL_USER` / `MYSQL_PASSWORD` | 业务库账号 |
| `MCP_SECURITY_SECRETKEY` | AES-256 密钥，Base64 32 字节；用于工具凭证加密 |
| `MCP_ADMIN_JWT_SECRET` | 后台 JWT 签名密钥，≥32 字符 |
| `MCP_ADMIN_INIT_PASSWORD` | 首次启动超管密码，≥8 位 |
| `MCP_INTERNAL_TOKEN` | 控制面 → 数据面 `/internal/**` 共享凭证 |
| `MCP_PUBLIC_BASE_URL` | discovery 返回给客户端的绝对地址 |

### 2.2 常用

| 变量 | 默认 | 说明 |
|---|---|---|
| `SPRING_PROFILES_ACTIVE` | `dev` | 生产填 `prod` |
| `JAVA_OPTS` | `-Xms512m -Xmx1024m` | 两个 JVM 各自生效 |
| `MCP_SWAGGER_ENABLED` | `false` | 生产保持关闭 |
| `MCP_SECURITY_ALLOW_PRIVATE_NETWORK` | `false` | 下游都是内网时才开；开启会放开 SSRF 防护 |
| `MCP_REDIS_ENABLED` | `false` | 多副本必须 true |
| `MCP_REDIS_URL` | `redis://127.0.0.1:6379/0` | 统一 Redis 地址；兼容旧 `MCP_REDIS_URI` |
| `MCP_IDENTITY_ENABLED` | `false` | 是否向 downstream 签发内部断言 |
| `MCP_IDENTITY_MODE` | `OPTIONAL` | `OFF` / `OPTIONAL` / `REQUIRED` |
| `MCP_IDENTITY_TOKEN_FORMAT` | `JWE`（生产常用 JWS） | `JWS` 只签名；`JWE` 需要下游公钥 |
| `MCP_IDENTITY_SIGNING_KEY` | 空 | 生产必须固定配置，否则重启后下游验签失败 |
| `MCP_IDENTITY_FORWARD_USER_TOKEN` | `false` | 仅可信下游开启原始用户 token 透传 |
| `MCP_ADMIN_JWT_TTL_HOURS` | `168`（7 天） | 后台登录有效期（小时）；支持 `1`～`168`：低于 1 按 1 小时、超过按 7 天、非法值按默认 168 小时处理并告警 |

### 2.3 可选/开发专用

| 变量 | 说明 |
|---|---|
| `MCP_AUTH_STATIC_TOKENS` | **仅本地/E2E**，生产配置会启动失败 |
| `MCP_TOOLS_PROFILE` | `default` / `compact` / `large` |
| `MCP_TOOLS_META_ENABLED` | 应急回退：false 时全部按 DIRECT |
| `MCP_TOOLS_CHUNK_STORE` | `memory` / `redis`；多副本建议 redis |
| `MCP_EMBEDDING_KEY` | 语义检索 key；不配则降级词法检索 |
| `MCP_DB_URL` | 可选，改用外部 MySQL 时覆盖 JDBC URL |

> 旧的 `MCP_AUTH_USER_TOKEN_HEADER`、`MCP_IDENTITY_SIGNING_KID`、`MCP_IDENTITY_USER_TOKEN_HEADER`、
> `MCP_TOOLS_REDIS_URI` 已不再需要；仍设置也不会报错（部分作为兼容回退保留）。

## 3. 工具治理档位

```bash
MCP_TOOLS_PROFILE=default   # 默认，不注入任何预设
MCP_TOOLS_PROFILE=compact   # 小上下文：更小分页/预算/描述
MCP_TOOLS_PROFILE=large     # 大工具量：更大分页/预算
```

| 属性 | default | compact | large |
|---|---:|---:|---:|
| `page-size` | 200 | 100 | 200 |
| `pagination-min-tools` | 500 | 300 | 1000 |
| `asset-pagination-min` | 500 | 300 | 1000 |
| `warn-threshold` | 100 | 60 | 200 |
| `max-threshold` | 500 | 200 | 800 |
| `search-limit` | 10 | 8 | 15 |
| `max-search-limit` | 50 | 30 | 50 |
| `hot-tool-limit` | 50 | 30 | 50 |
| `max-description-length` | 1200 | 800 | 1500 |
| `search-description-length` | 300 | 200 | 300 |
| `result-spill-threshold` | 4000 | 3000 | 6000 |
| `chunk-limit` | 3000 | 2000 | 4000 |

规则：

- 档位是“低优先级预设”，**显式单项覆盖优先**；
- 例如 `MCP_TOOLS_PROFILE=compact` + `MCP_TOOLS_PAGE_SIZE=120`，最终 `page-size=120`；
- 未知档位会启动失败（配置自检）。

## 4. 高级层：需要时再覆盖

这些不再写进 `.env`，但都可以用 Spring 属性或环境变量覆盖。示例：

```bash
# 方式一：环境变量
MCP_TOOLS_PAGE_SIZE=120
MCP_SESSION_MAX_COUNT=50000

# 方式二：启动参数（推荐排障时临时用）
java -jar dataplane.jar --mcp.tools.page-size=120 --mcp.health.probe-interval-ms=60000
```

### 4.3.1 多租户访问拓扑（Namespace / Endpoint）

| 资源 | `tenant_id` | 谁能管理 | 可绑定范围 |
|---|---|---|---|
| 平台级 Namespace / Endpoint | `NULL` | 仅平台超管 | 可跨业务方聚合多个租户的 Server（"多业务方聚合到同一端点"） |
| 业务方级 Namespace / Endpoint | 业务方 ID | 该业务方管理员（ADMIN） | 只能绑定/引用本业务方的 Server 与 Namespace |

- 租户管理员（ADMIN）创建 Namespace/Endpoint 时自动归属本业务方，且列表只返回本业务方资源；
- 平台级资源不出现在租户管理员列表中，仅超管可见/可改；
- 数据面运行时仍按 Endpoint 绑定的 Server 集合暴露工具；跨租户聚合只允许由超管在平台级 Endpoint 上配置；
- 存量数据升级后 `tenant_id = NULL`（视为平台级），行为不变。迁移脚本：`db/mysql/migrations/20261025_topology_tenant.sql`（启动前手动执行，幂等）。

> 安全提示：`GET /mcp/admin/tools` 等查询接口不再回传 `authConfig` 明文，只返回 `authConfigSet`；修改凭证仍需审批（L2），连通性测试复用库中凭证仅对管理员开放。

## 5. 启动自检

应用启动时会做一次低成本检查，失败直接拒绝启动：

- 生产环境配置了 `MCP_AUTH_STATIC_TOKENS`；
- `MCP_IDENTITY_MODE` 不是 `OFF/OPTIONAL/REQUIRED`；
- 生产 + `REQUIRED` 但没有 `MCP_IDENTITY_SIGNING_KEY`；
- `MCP_REDIS_ENABLED=true` 但未显式配置 `MCP_REDIS_URL`（生产拒绝启动，非生产仅告警；YAML 默认值不算显式配置）；
- `MCP_TOOLS_PROFILE` / `--mcp.tools.profile` 不是 `default/compact/large`。

以下情况只告警，不阻断：

- 生产开启 `MCP_IDENTITY_FORWARD_USER_TOKEN`；
- 生产开启 `MCP_SECURITY_ALLOW_PRIVATE_NETWORK`；
- 生产 `MCP_PUBLIC_BASE_URL` 仍指向 `127.0.0.1`。

## 6. 资源层：Server/Endpoint 字段

| 表 | 字段 | 作用 |
|---|---|---|
| `mcp_server` | `identity_mode` | `INHERIT/OFF/OPTIONAL/REQUIRED` 覆盖全局 |
| `mcp_server` | `audience` / `identity_public_key` | 下游断言 audience / JWE 公钥 |
| `mcp_server` | `tool_exposure_mode` | `DIRECT` / `META` |
| `mcp_server` | `hot_tool_codes` | META 常驻热工具 |
| `mcp_server` | `tool_warn_threshold` / `tool_max_threshold` | 单 Server 预算阈值 |
| `mcp_server` | `status` / `upstream_type` / `upstream_url` | 启停与上游 |
| `mcp_endpoint` | `endpoint_key` / `status` | 对外接入点 |
| `mcp_namespace` | `prefix` | 工具名前缀 |
| `mcp_tool` | `code` / `type` / `auth_type` / `auth_config` | 工具定义与凭证 |

这些都在控制台维护，不需要改 `.env` 或重启。

## 7. 常见调整

```bash
# 工具太多，想让客户端少拉一点
MCP_TOOLS_PROFILE=compact

# 客户端明确支持分页，想减少一次返回
MCP_TOOLS_PAGE_SIZE=100

# 多副本 + 超长结果分片
MCP_REDIS_ENABLED=true
MCP_REDIS_URL=redis://127.0.0.1:6379/0
MCP_TOOLS_CHUNK_STORE=redis

# 只对某个 Server 灰度身份下传
# 控制台 → Server → 下游身份下传 → OPTIONAL
```
