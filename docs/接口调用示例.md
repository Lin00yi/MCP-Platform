# MCP 网关后端接口调用示例

> 认证基线：网关只认 `x-dsh-auth-token`（`dsh_` / PAT）；应用维度、`access-token`、`appId` 已删除。
> 客户端唯一入口：`/mcp/e/{endpointKey}`；管理面统一 `/mcp/admin/**`。

```bash
ADMIN=http://localhost:8082
DP=http://localhost:8081
USER_TOKEN=<dsh_/PAT>
ADMIN_TOKEN=<登录返回的 JWT>
```

---

## 0. 先决条件

数据库已执行 `db/mysql/init.sql`（新装）或 `docs/sql/migration.sql` + 增量脚本（存量）。
至少有一个 Endpoint 绑定 Namespace，Namespace 里包含 Server；否则数据面会返回 403/空列表。

---

## 1. 管理接口（控制面 :8082）

### 1.1 登录

```bash
curl -s -X POST "$ADMIN/mcp/admin/auth/login" \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"<初始密码>"}'
# → {"code":0,"data":{"token":"<JWT>","user":{...}}}
```

后续管理接口：

```bash
-H "Authorization: Bearer $ADMIN_TOKEN"
```

### 1.2 业务方 / Server / Tool

```bash
# 业务方
curl -s "$ADMIN/mcp/admin/tenants" -H "Authorization: Bearer $ADMIN_TOKEN"
curl -s -X POST "$ADMIN/mcp/admin/tenants" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{"name":"crm","status":1}'

# Server（path 仅作标识，不注册 /mcp/v1）
curl -s -X POST "$ADMIN/mcp/admin/servers" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{
    "tenantId":1,"name":"crm-server","path":"/assets/crm","status":1,
    "toolExposureMode":"DIRECT","identityMode":"INHERIT"
  }'

# 本地 Tool（type=0，serviceUrl=LocalToolsService.方法名）
curl -s -X POST "$ADMIN/mcp/admin/tools" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{
    "serverId":1,"name":"两数相加","code":"add","type":0,"status":1,
    "serviceUrl":"LocalToolsService.add","authType":"NONE",
    "resJson":"{\"name\":\"add\",\"description\":\"两数相加\",\"inputSchema\":{\"type\":\"object\",\"properties\":{\"a\":{\"type\":\"number\"},\"b\":{\"type\":\"number\"}},\"required\":[\"a\",\"b\"]}}"
  }'
```

### 1.3 Namespace / Endpoint（客户端唯一入口）

```bash
# Namespace：prefix 是工具名前缀
curl -s -X POST "$ADMIN/mcp/admin/namespaces" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{"name":"CRM","prefix":"crm","status":1}'

# Namespace 绑定 Server
curl -s -X PUT "$ADMIN/mcp/admin/namespaces/1/servers" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{"serverIds":[1]}'

# Endpoint：key 即 /mcp/e/{endpointKey}
curl -s -X POST "$ADMIN/mcp/admin/endpoints" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{"endpointKey":"crm","name":"CRM 接入点","status":1}'

# Endpoint 绑定 Namespace
curl -s -X PUT "$ADMIN/mcp/admin/endpoints/1/namespaces" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{"namespaceIds":[1]}'
```

### 1.4 暴露策略 / 阈值

应用授权已移除，不再有 WHITELIST；只保留 DIRECT/META、热工具与阈值：

```bash
# 查看预算
curl -s "$ADMIN/mcp/admin/servers/1/tool-budget" -H "Authorization: Bearer $ADMIN_TOKEN"

# META + 热工具 + 阈值
curl -s -X PUT "$ADMIN/mcp/admin/servers/1/tool-exposure" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{
    "toolExposureMode":"META","hotToolCodes":["add"],
    "toolWarnThreshold":50,"toolMaxThreshold":200
  }'

# 按调用记录推荐热工具
curl -s "$ADMIN/mcp/admin/servers/1/hot-tools/recommend?days=30&limit=20" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

### 1.5 身份下传（下游内部断言）

```bash
# Server 级覆盖：INHERIT（默认）/OFF/OPTIONAL/REQUIRED
curl -s -X PUT "$ADMIN/mcp/admin/servers/1" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{
    "audience":"crm-downstream",
    "identityPublicKey":"-----BEGIN PUBLIC KEY-----\n...\n-----END PUBLIC KEY-----",
    "identityMode":"OPTIONAL"
  }'
```

全局模式由 `MCP_IDENTITY_ENABLED` + `MCP_IDENTITY_MODE` 控制；JWE 模式必须配置下游公钥。

### 1.6 OpenAPI 批量导入

```bash
curl -s -X POST "$ADMIN/mcp/admin/tools/openapi/preview" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{"serverId":1,"document":"<OpenAPI JSON 字符串>"}'

curl -s -X POST "$ADMIN/mcp/admin/tools/openapi/import" -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{
    "serverId":1,"document":"<OpenAPI JSON 字符串>","codes":["crm_order_get"],
    "conflictPolicy":"SKIP"
  }'
```

### 1.7 刷新资产缓存

```bash
curl -s -X POST "$ADMIN/mcp/admin/refresh-server-api" -H "Authorization: Bearer $ADMIN_TOKEN"
# → 通知数据面清空工具/资产缓存并广播 list_changed（不再注册 /mcp/v1 路由）
```

## 2. MCP 协议接口（数据面 :8081）

### 2.1 initialize

```bash
ENDPOINT_KEY=crm
SID=$(curl -s -D - -o /dev/null -X POST "$DP/mcp/e/$ENDPOINT_KEY" \
  -H 'Content-Type: application/json' \
  -H "x-dsh-auth-token: $USER_TOKEN" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"curl","version":"1"}}}' \
  | grep -i mcp-session-id | tr -d '\r' | awk '{print $2}')
```

响应头含 `Mcp-Session-Id`，后续请求都要带。

### 2.2 tools/list

```bash
curl -s -X POST "$DP/mcp/e/$ENDPOINT_KEY" \
  -H 'Content-Type: application/json' \
  -H "x-dsh-auth-token: $USER_TOKEN" \
  -H "Mcp-Session-Id: $SID" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list"}'
```

工具名是暴露名：`{namespacePrefix}__{code}`，例如 `crm__add`。
`_meta` 里含 `accessMode=AGGREGATE`、`exposureMode`、`returnedTokens` 等。

### 2.3 tools/call

```bash
curl -s -X POST "$DP/mcp/e/$ENDPOINT_KEY" \
  -H 'Content-Type: application/json' \
  -H "x-dsh-auth-token: $USER_TOKEN" \
  -H "Mcp-Session-Id: $SID" \
  -d '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"crm__add","arguments":{"a":3,"b":4}}}'
# → {"result":{"content":[{"type":"text","text":"3.0 + 4.0 = 7.0"}]}}
```

### 2.4 prompts / resources

```bash
curl -s -X POST "$DP/mcp/e/$ENDPOINT_KEY" \
  -H 'Content-Type: application/json' -H "x-dsh-auth-token: $USER_TOKEN" \
  -H "Mcp-Session-Id: $SID" \
  -d '{"jsonrpc":"2.0","id":4,"method":"prompts/list"}'

curl -s -X POST "$DP/mcp/e/$ENDPOINT_KEY" \
  -H 'Content-Type: application/json' -H "x-dsh-auth-token: $USER_TOKEN" \
  -H "Mcp-Session-Id: $SID" \
  -d '{"jsonrpc":"2.0","id":5,"method":"resources/read","params":{"uri":"crm__file://readme"}}'
```

### 2.5 发现

```bash
curl -s "$DP/mcp/discovery/servers" -H "x-dsh-auth-token: $USER_TOKEN"
curl -s "$DP/mcp/discovery/tools?q=add" -H "x-dsh-auth-token: $USER_TOKEN"
# ETag / 304
curl -s -D - "$DP/mcp/discovery/servers" -H "x-dsh-auth-token: $USER_TOKEN" \
  -H 'If-None-Match: "<上次的 ETag>"'
```

## 3. MCP 客户端配置

```json
{
  "mcpServers": {
    "mcp-gateway": {
      "url": "https://mcp.example.com/mcp/e/crm",
      "headers": { "x-dsh-auth-token": "<dsh_/PAT>" }
    }
  }
}
```

Codex / Claude / Cursor 的 `url` + `headers` 形式同上；只支持 stdio 的客户端需要桥接进程注入
`x-dsh-auth-token`。详见 [MCP客户端接入指南.md](MCP客户端接入指南.md)。

## 4. 错误码速查

| 场景 | HTTP / JSON-RPC | 说明 |
|---|---|---|
| 缺/错用户 token | 401 | `x-dsh-auth-token` 无效或过期 |
| token 存储不可用 | 503 | user-center `UserTokenStore` 未接入/故障，不是 token 失效 |
| Endpoint 不存在/停用 | 403 | 检查 `/mcp/admin/endpoints` |
| 缺会话 | 400 / `-32600` | 先 `initialize` 并带 `Mcp-Session-Id` |
| 工具不存在 | `result.isError=true` | 用暴露名 `{prefix}__{code}` |
| 身份下传 REQUIRED 失败 | `-32003` | 缺客编/下游公钥/签发失败；看数据面日志 |
| 旧路径 `/mcp/v1/...` | 404 | 旧链路已下线，改用 `/mcp/e/{key}` |
