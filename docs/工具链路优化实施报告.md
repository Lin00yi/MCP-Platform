## 6. Prompt / Resource 轻量治理（2026-10-20）

Tool 的 META/热工具/Embedding 没有照搬到 Prompt/Resource，而是按真实成本处理：

| 能力 | 实现 |
|---|---|
| 访问模式 | `prompt_access_mode` / `resource_access_mode`：WHITELIST / ALL（与 Tool 同一枚举） |
| 双重鉴权 | 拦截器 `checkPromptPermission` / `checkResourcePermission` + 服务层 `AssetAccessPolicy` |
| 内容上限 | Prompt 256KB、Resource 1MB、Tool 结果 1MB，UTF-8 安全截断 |
| 分页 | prompts/resources/resources-templates 支持 cursor，门槛 500，`_meta` + `paginationRisk` |
| 缓存 | `PromptListCache` / `ResourceListCache` + `prompts/list_changed` / `resources/list_changed` |
| 标签 | `tags` + 发现接口 `tag` 过滤 |
| 预算 | `totalPrompts/visiblePrompts/...` + 告警 |
| 授权补齐 | 授权 Server 时自动补齐当前 Prompt/Resource；新增资产仍需显式授权 |

详细说明见 [Prompt 与 Resource 治理](Prompt与Resource治理.md)。

## 7. 说明与边界

- Embedding 使用 OpenAI 兼容协议，当前本地未配置 `MCP_EMBEDDING_KEY`，生产接入前需确认供应商的请求/响应字段；
- token 估算为 CJK-aware 近似值，不是模型官方 tokenizer，不用于计费；
- 分页客户端白名单基于 `clientInfo.name` 子串匹配，未知客户端超过 500 工具时返回 `paginationRisk=true`；
- 应用级 `ALL` 是覆盖 Server 模式的逃生门，审计日志会记录；
- 当前 `pcb-server` 仍为 `WHITELIST + META`，`codex-pcb` 的工具授权在 08:39 被撤销（0 条），需要时可使用补齐接口恢复。
